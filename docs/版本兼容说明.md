# 版本、组件与兼容边界

## 选择配套组件

Android App 与电脑插件独立发布，不要求版本号相同或每次同时升级。
请从 [GitHub Releases](https://github.com/y8n/dsh-mobile-app/releases) 查看所选版本的宿主要求、配套插件和已验证范围。
当前源码版本由构建清单维护，机器配置见 [compatibility.json](../config/compatibility.json)，不在使用指南重复固定版本号。

只安装一个移动访问插件，独立原插件与整合包同时启动网关不是支持方案。
插件对部分宿主模块做固定哈希校验；宿主更新后应使用配套插件，不可绕过校验。
Node 要求见插件 package.json 的 engines，Android 最低系统要求见 app/build.gradle.kts。
声明支持的最低系统与实际测试范围应分开理解，未验证的组合不保证可用。

## 当前电脑插件修复

电脑插件 0.2.1 对应的已验证宿主基线为 DeepSeek Harness Desktop 0.2.1-rc.3，兼容已有 Android 0.2.1。本次升级仅需更新电脑插件并重新连接手机，不需要新的 APK，也不需要重新配对或清理证书。

此版本适配宿主的 owner Peer 权限模型和未打开会话的摘要参数。通知独立于定时任务适配器加载；定时任务仍校验已验证模块的哈希，未知宿主版本不会自动获得支持。其他宿主组合及手机锁屏送达条件不能仅凭版本号推定可用。

## 依赖与降级

- 定时任务依赖 mobileSchedule/capabilities（version=1、lifecycle、durableRequestIdentity）及 catalog/history/写接口。
  有基础读接口回退不代表完整写生命周期可用。
- 搜索、列表分页、待确认恢复：mobileSearch/searchWorkspace、mobileSearch/listWorkspace、mobileSearch/lookupPrompt。
- 附件及电脑文件读取：mobileAttachments/stat、mobileAttachments/readRange。普通附件上传复用宿主 /api/session/uploadFileBinary 流式接口；大小还受网关与远程通道限制。
- 通知补查与详情：mobileNotifications/poll、mobileNotifications/details。
- 用量：mobileAccount/summary；桌面账号令牌缺失时累计消费未知，WebUI 并非全功能桌面账号登录入口。

只有部分接口有 capabilities；没有统一的全功能跨版本握手，不凭插件版本号展示全部操作。
网络、手机后台限制、权限、宿主功能及插件加载结果都是运行条件；npm 安装成功不等于整条业务验收。

- 手机诊断上传依赖 mobileDiagnostics/upload；只写接收电脑的本地临时目录，旧插件缺少接口时日志留在手机。

## 升级

新增能力先兼容旧端，明确不可用状态；通常先升级能够继续服务旧 App 的插件，再分发新 App。
如果接口语义或鉴权有破坏性变化，应明确配套升级和回滚，不盲目套用该顺序。
每次发布记录源码 SHA、版本、产物哈希和测试边界；未经测试的组合写未验证。
