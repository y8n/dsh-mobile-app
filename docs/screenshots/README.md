# 截图与 UI 变化

截图由 PublicShowcaseTest 在专用 Android API 35 模拟器中运行生产 Compose 组件生成。
使用虚构的“演示电脑”“示例项目”“发布准备”会话，以及明确模拟的用量和使用时长；不连接真实电脑。
部分交互组件以独立 fixture 页面展示，不应误认为已有真实任务正在运行。

首页基础展示：工作区、会话列表、消息、添加连接、插件列表、diff。
增强展示：设备用量与本地使用时长、浅/深色主题、Markdown 控件、目标浮动栏及权限确认。
原生 UI 与原项目 WebView 容器的区别见 [增强说明](../guide/enhancements.md)。原作者 UI 仅链接其公开文档，
不复制其中的个人连接信息或不明授权背景插画；感谢 saya-ch/dsh-mobile 提供基础项目。

图像保留原生界面和系统栏，不把设计效果图冒充运行截图。采集脚本与实际 SHA-256 在 manifest.json 中记录。
模拟器截图不能证明所有 Android 版本、厂商、网络、后台和锁屏行为均已验收。
