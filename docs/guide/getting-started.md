# 快速开始

先感谢 [saya-ch/dsh-mobile](https://github.com/saya-ch/dsh-mobile)：本项目的安全移动访问与配对来自该项目，
电脑插件已整合其基础能力，不需要再装第二个移动网关。

## 安装电脑插件

在 DeepSeek Harness 的插件管理页面输入 `@dsh-mobile-app/desktop-extension`，选择 npm 官方源。
如所选 Release 指定配套插件版本，请按该说明选择。
不要在普通系统目录 npm install 后就假定宿主已启用；它是宿主 Bundle，需要由宿主插件管理器加载。

插件带固定模块校验，宿主更新后可能需要配套升级；安装前核对 Release 中的宿主要求，见[兼容说明](../版本兼容说明.md)。

### 从原插件迁移

先记录旧插件版本、配置及启用状态，备份原 mobile-access 配置、设备和证书资料，不要发到 Issue。
在隔离环境确认后，停用旧移动 Bundle，启用整合 Bundle；保持只运行一个网关。
不要清空普通配对、工作区、会话或手工编辑数据库。失败时恢复旧 Bundle 和原配置，不启动两个网关“兜底”。
已有配对能否保留需对当次宿主和插件逐项回读，不因安装 npm 成功就宣称已完成业务迁移。

## 建立手机与电脑的连接

从 [GitHub Releases](https://github.com/y8n/dsh-mobile-app/releases) 下载本项目的 Android App，并阅读配套要求；也可按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 构建源码。

**在家用局域网，在外用隧道。** 两种连接可以保存在同一台设备下，以后只需手动切换，不用反复添加或删除设备。电脑端需要保持 DeepSeek Harness 和对应访问通道运行。

### 1. 在电脑端配置访问

电脑端网络配置沿用老插件的能力，详细图文步骤直接参考原作者的 [README 连接教程](https://github.com/saya-ch/dsh-mobile#连接教程)：

- **在家连接：[局域网访问教程](https://github.com/saya-ch/dsh-mobile#局域网访问)**。手机与电脑接入同一可信局域网，在电脑的“移动访问 → 局域网”中开启访问并生成配对信息。
- **外出连接：[远程访问教程](https://github.com/saya-ch/dsh-mobile#远程访问)**。在电脑的“移动访问 → 远程”中配置隧道，等通道就绪后生成该入口的配对信息。账号、域名等前置条件与各通道操作见原教程。

这里只复用原教程的**电脑端网络配置步骤**：安装的插件仍是本项目的 `@dsh-mobile-app/desktop-extension`，手机也使用本项目 App，无需再安装老插件或下载其 App。上游 README 会持续更新，通道是否可用以当前整合插件面板为准；本项目 App 的添加设备操作见下文。

### 2. 在手机端首次添加设备

1. 打开 App；没有设备时进入添加设备页面，有设备时从设备列表添加。
2. 填写设备名称和电脑端显示的 **HTTPS 连接地址**，粘贴该连接对应的**配对密钥**。不要把 DeepSeek API key 当作配对密钥。
3. 如果使用局域网入口，勾选“局域网连接”；使用公网隧道则不勾选。连接地址与密钥必须来自同一入口。
4. 点击连接，核对配对信息与服务身份；成功后进入工作区列表，即可打开会话发送消息。

第一个设备自动成为默认设备，之后启动 App 会进入它的工作区。请使用电脑端实际显示的地址和端口，不要将桌面 WebUI 地址误作移动网关地址。

### 3. 给同一电脑添加另一种连接

例如已经在家通过局域网配对，希望外出也能使用：

1. 在电脑端配置远程通道并生成远程配对信息，步骤见上方原作者教程。
2. 在手机的工作区列表点击右上角设置，进入**当前设备的设置页**。
3. 点击“连接方式”标题旁的 **＋**，填写连接名称（如“外出隧道”）、隧道 HTTPS 地址及对应配对密钥，完成配对。
4. 两条连接保存在同一设备下；同样也可以给先通过隧道添加的设备补充“家中局域网”连接。

每个地址需要独立配对，并且必须属于同一个 DeepSeek Harness 实例。提示实例不一致时，请确认配对信息来自同一台电脑的同一实例。

### 4. 在家和外出时快速切换

进入**设备设置 → 连接方式**，点击所需连接左侧的选项：在家选择局域网，外出选择隧道。App 使用你手动选中的连接，不会按优先级自动切换。

隧道地址改变、配对密钥过期或证书变化时，先到电脑面板确认最新信息，再重新配对；不要通过关闭 TLS 校验或清空 App 数据解决。换成手机移动网络后可验证隧道是否能从外网访问。

设备列表的管理入口负责全局主题、默认设备和本地缓存；工作区页右上角设置负责当前设备的连接、使用信息和诊断日志上传。

## 会话、文件与任务

在会话列表选择已有会话或新建会话；模型、权限和执行均由电脑侧处理。
本地文件 Markdown 链接通过电脑侧文件服务读取，原 Markdown 不改写；不意味着可以任意读取电脑全部文件。
不支持的类型不强制当作文本显示，查看/分享文件前确认内容没有秘密。

普通附件复用 DeepSeek Harness 的二进制上传接口，手机以流式读取发送，不再设置 8 MiB 上限。
实际允许大小受电脑网关和远程通道限制；图片另按电脑返回的图片大小、像素及格式要求检查。
流式上传不代表断点续传。出现“上传结果尚未确认”时，先核对电脑端结果，避免重复上传。

定时任务页仅展示活动任务；新增入口隐藏，由 AI 发起新增。目标状态、人工确认和权限批准均是实际业务操作，
不要为了测试而批准对真实工作区的改动。示例截图不连接实际电脑。

## 通知与华为后台设置

完成、提问和权限三类通知需要通知权限和可用事件连接。正在前台使用同一会话时不重复提醒。
在华为系统中，通常需要在“应用启动管理”等系统入口允许 App 后台运行；具体名称随系统版本变化。
此前测试确认，不允许后台运行会出现“退后台收不到、回前台补发”。不要把它当成所有通知问题的唯一原因。
当前方案不等于 HMS/FCM 厂商系统推送；进程被终止或系统限制时不承诺后台/锁屏送达。

## 故障与隐私

先确认当前连接、电脑插件启用状态、宿主版本和网络。不要把“操作待确认”当成必然失败而重复提交有副作用的操作。
默认仅本地诊断记录，无开发者个人上传服务；可以主动上传到已配对电脑，见[日志上传与本地排查](diagnostics.md)；可清理本地日志，手机清理不会删除电脑已接收的副本。
提交问题使用虚构复现数据，遵循 [隐私说明](../../PRIVACY.md) 和 [安全报告](../../SECURITY.md)。
