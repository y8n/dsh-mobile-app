# 相对原项目的增强与 UI 变化

**原作者：saya-ch 及 dsh-mobile 贡献者。** 比较基线为本项目整合时的 [dsh-mobile](https://github.com/saya-ch/dsh-mobile) 源码，具体修订见 [来源记录](../../CREDITS.md)，
不把原项目后续版本或 DeepSeek Harness 本身的功能混在一起比较。

## 沿用的基础能力

电脑端 HTTPS 网关、设备配对、Cookie/Origin/证书约束、LAN/远程通道、网页适配、CLI 与 question-fixes 来自原项目，
原始发布归档和许可保留。DeepSeek Harness 提供会话、工作区、模型、工具、权限与代理执行等业务。
原项目通过 DSH 网页本来就能显示 Markdown、文件、工具等内容，这些不是本项目首次创造的能力。

本项目的基本原生页面见首页“功能与界面”截图：工作区、会话列表、消息、添加连接、插件列表及 diff。

## 核实的实现差异

### 1. 原生界面与交互

使用 Kotlin / Jetpack Compose 重建 Android 界面，从原项目的 WebView 网页访问方式改为原生页面。工作区、会话、输入框和设备设置针对手机操作设计；执行过程更紧凑，回答完成后折叠过程，方便阅读结果。

下图从左到右为工作区、会话、设备设置，合并自三张模拟器截图。

![原生工作区、会话与设备设置](../screenshots/native-pages-light.png)

### 2. 原生文件与查看器

在手机上打开电脑文件，使用原生界面查看文件卡片、代码差异和图片。Markdown 中的文件链接由 App 解析并向电脑读取内容，不修改原文档，电脑端仍可照常使用。代码块支持复制和切换折行。

下图从左到右为文件改动列表、diff 查看器、文件类型与图片预览组件。

![原生文件改动、diff 和文件类型预览](../screenshots/file-viewers-light.png)

### 3. 多连接通道

同一台电脑可以保存多个连接：**在家用局域网，在外用隧道**，按场景手动切换，不用重复添加设备。连接能力沿用原项目网关，App 增强同一设备下的连接管理，不会自动按优先级切换。

<p align="center"><img src="../screenshots/device-settings-light.png" width="300" alt="同一设备保存家中局域网和外出隧道两个连接"></p>

### 4. 设备使用时间

按设备统计 App 在前台使用其页面的时间，展示今天和近 7 天的耗时柱状图，后台运行不计入。数据只保存在手机本地，可在清除缓存时清理。

<p align="center"><img src="../screenshots/device-usage-light.png" width="300" alt="设备今天与近七天使用时长"></p>

### 5. 账户余额展示

设备设置中展示充值余额、赠送余额和累计消费。通过 API 获取，可能与官网数据有偏差，实际以官方平台数据为准。累计消费依赖电脑上的桌面账号凭据，无法读取时显示“未知”并提供说明。

<p align="center"><img src="../screenshots/device-settings-light.png" width="300" alt="设备设置中的充值余额、赠送余额与累计消费"></p>

### 6. 通知消息

分别提醒 **AI 回答完成、AI 提问确认、权限申请**，使用不同图标与文案，点击通知进入对应会话。正在前台查看该会话时不重复通知。后台送达仍依赖 Android 与厂商的后台权限；华为等设备需要允许后台运行。

以下是模拟器中使用虚构事件生成的系统通知，仅展示通知样式，不代表真机后台送达测试。

<p align="center"><img src="../screenshots/notifications-light.png" width="300" alt="回答完成、提问确认和权限申请三类系统通知"></p>

### 7. Git 分支显示与发送待确认恢复

Git 工作区的会话标题下显示当前分支，非 Git 工作区不显示。网络中断导致发送结果不确定时，保留待确认消息，支持核对真实会话及解除待确认后继续操作，避免盲目重复发送。

下图展示会话标题下的 Git 分支；发送待确认是异常恢复能力，不是图中的正常会话状态。

<p align="center"><img src="../screenshots/conversation-branch-light.png" width="300" alt="会话标题下展示 main 分支"></p>

### 8. 日志上传与开发排查

诊断日志默认保存在手机本地。需要排查时，在单个设备的设置中上传到该配对电脑，沿用已有连接与鉴权，日志落在电脑的专用临时目录，不依赖云存储。报告编号和保存位置方便开发者及 AI 定位问题；自动上传需单独开启。

<p align="center"><img src="../screenshots/device-diagnostics-light.png" width="300" alt="单个设备的日志上传和日志位置复制入口"></p>

## 不保证覆盖原项目的全部网页扩展

原项目 `/mobile` CSS/JS 定制、网页侧栏扩展和网页语音桥接不会自动驱动原生 Compose 页。
本项目保留整合插件的网页入口，但原生客户端不是任意浏览器插件的兼容层。
各能力依赖、宿主固定模块校验和实际验证范围见 [版本兼容](../版本兼容说明.md)。
