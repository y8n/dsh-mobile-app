# 电脑插件功能说明

## 0.2.1-beta.1

- 适配 DSH Desktop 0.2.1-rc.3 的 Peer 权限模型，修复会话列表、附件及电脑诊断接口的内部错误。
- 修复未打开会话的分页摘要参数。
- 通知独立加载，避免定时任务版本检查失败时通知接口返回 404。
- 新增已验证的定时任务模块版本，保留未知版本拒绝机制和委派目标限制。
- Android 无需更新；手机通知显示、锁屏送达和点击跳转仍需真机验收。

## 基础功能

- 整合 dsh-mobile 的网关、配对、局域网与远程通道，使用一个电脑插件提供移动访问。
- 提供原生 App 所需的附件读取、会话搜索、发送恢复、定时任务、通知和用量接口。
- 分发包收录 Apache-2.0 LICENSE、NOTICE、第三方许可及资源来源。
- 不内嵌个人测试 APK 下载地址，不预配置使用者的隧道、配对或服务凭据。

Android App 与电脑插件独立发布；宿主和功能依赖见仓库中的版本兼容说明。
手机后台通知仍受系统运行权限和网络条件影响。
